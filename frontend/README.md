# TrueTone - Frontend Application

TrueTone's frontend is a Single Page Application (SPA) built with React 19 and Vite. It provides a highly interactive, dynamic, and aesthetic user interface for AI-powered skin analysis, personalized product recommendations, and ingredient scanning.

## Tech Stack

- **Core Framework**: React 19 + Vite 7
- **Routing**: React Router v7
- **Styling**: Tailwind CSS (v4)
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Network / API**: Axios
- **Other Utilities**: `react-image-crop` (for product scanning), `react-markdown` (for chatbot rendering), `@mediapipe/tasks-vision`

## Key Features & Pages

### 1. Skin Analysis Pipeline (`SkinAnalysis.jsx`)
Guides the user through uploading or capturing a face image, confirming quality, showing dynamic scanning animations, and displaying the parsed results (Skin Type, Tone, and Disease) generated by the Django backend's parallel ML models.

### 2. Onboarding Flow (`Onboarding.jsx`)
A comprehensive multi-step form that collects crucial user data:
- General demographics (Age, Gender)
- Skin concerns and known skin types
- Safety flags (Pregnancy status, specific allergies)
- Current products in use

### 3. Product Scanner (`ProductScanner.jsx`)
Allows users to upload an image of a skincare product's ingredient list. Uses `react-image-crop` to let users manually crop and isolate the text, which is then sent to the backend's Gemini OCR scanner for safety analysis against their known allergies and profile.

### 4. Skin Tracking (`SkinTracking.jsx`)
Provides a historical timeline of past skin scans, complete with pop-up image overlays to visually track skin condition progress and changes over time.

### 5. Personalized Recommendations (`Recommendations.jsx`)
Displays a ranked list of skincare products tailored to the user's profile, explicitly filtering out allergens or unsafe ingredients based on their onboarding data.

### 6. Skincare Chatbot (`Chatbot.jsx`)
A conversational interface built with `react-markdown` that chats with the backend's Gemini AI, automatically injecting the user's active skin profile into the prompt context for highly personalized advice.

## How to Run Locally

### 1. Install Dependencies
```bash
cd frontend
npm install
```

### 2. Configure Environment Variables
Create a `.env` file in the `frontend` root directory to point to your backend API.
```env
VITE_API_BASE_URL=http://localhost:8000
```
*(Ensure the backend Django server is running simultaneously)*

### 3. Start the Development Server
```bash
npm run dev
```
The application will be available at `http://localhost:5173`.

### 4. Build for Production
To create a production-ready optimized build:
```bash
npm run build
```
The compiled, minified files will be output to the `dist/` directory.
